          How it forges · scroll
          
Six passes. Zero guesswork.

          

            hey can u
            make me a landing page
            for my bakery,
            should look nice and
            load fast.
            dont use bootstrap
            pls thx
          

          

            target → Claude
            intent → coding · confidence 0.92
            status → ready
          

        

        
    
          
  1. 1
    Normalize
    Strips pasted UI noise, protects code, detects the language, and redacts API keys before anything leaves your machine.
    2. 
          
  2. 2
    Detect the target
    Reads the page, app or editor you're in: Claude gets XML tags, ChatGPT gets Markdown, Cursor gets a brief.
    3. 
          
  3. 3
    Classify the intent
    Ten task types, from coding and debugging to email and image, including everyday Hinglish.
    4. 
          
  4. 4
    Extract the details
    Goal, audience, tone, tech, constraints, and any code or errors you pasted, copied verbatim.
    5. 
          
  5. 5
    Rewrite
    A local model like qwen2.5 rewrites to the target's playbook, within a word budget that fits the request.
    6. 
          
  6. 6
    Check and repair
    Every detail you gave must survive. If one goes missing, the model gets one repair pass listing exactly what to put back.
    7.
